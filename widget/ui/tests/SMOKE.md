```
cd widget
npm run tauri dev          # 或：cargo run --manifest-path widget/src-tauri/Cargo.toml
```

## 1. 载入

- [ ] 置顶小窗出现 4 个圆控件：GLM / Kimi（双环）、DeepSeek（圆心 CNY 87.50）、摆渡（虚线框）
- [ ] 环色：GLM 周环红（剩 8%）、Kimi 周环黄（剩 17%）、5h 环蓝；满弧=满额（剩余制）
- [ ] GLM/Kimi 圆控件下第一行是倒计时行（●2h28m · ●6d11h 式），颜色随所属环、告警加粗
- [ ] 右上角“演示数据”角标可见（release 构建不显示——用 `npm run tauri build` 产物复核一次）
- [ ] 单击圆控件 → 详情卡窗口内覆盖弹出（值/绝对数/重置时刻+倒计时/口径文案/最后更新），点空白处收起
- [ ] 悬停圆控件 → tooltip 出各环剩余与重置倒计时
- [ ] ⚙ → 设置浮层：切“横排”布局变化、关“显示重置倒计时行”倒计时行消失、图例帮助区完整
- [ ] 灰化态演示（可选）：用 Edge 直接打开 `widget/ui/index.html?dev=1&gray=1` → 整体灰化+“⚠ daemon 不可达”

## 2. 拖动

- [ ] 按住顶部 ⠿ 手柄拖动窗口到新位置，松手
- [ ] 重启应用 → 窗口回到上次位置（位置记忆）

## 3. 托盘

- [ ] 托盘右键 → “收起到托盘”：窗口隐藏
- [ ] 托盘右键 → “显示悬浮窗”：窗口恢复并聚焦
- [ ] 点窗口 ✕（无装饰框则跳过）→ 等价收起到托盘，进程不退出
- [ ] 托盘右键 → “退出”：进程结束

## 4. 倒计时走字

- [ ] 保持窗口开着等 1–2 分钟：倒计时行分钟位 −1（演示态以契约 generated_at 为锚随真实分钟推进；接真数据后为真实时钟）
