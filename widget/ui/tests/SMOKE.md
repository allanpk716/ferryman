# 票 03 · 壳内人工冒烟清单（晨间人工过）

启动（debug 构建即 dev 旗标，自动带“演示数据”角标）：

```
cd widget
npm run tauri dev          # 或：cargo run --manifest-path widget/src-tauri/Cargo.toml
```

## 1. 载入

- [ ] 置顶小窗出现 4 个圆控件：GLM / Kimi（双环）、DeepSeek（圆心 CNY 87.50）、摆渡（虚线框）
- [ ] 环色：GLM 周环红（剩 8%）、Kimi 周环黄（剩 17%）、5h 环蓝；满弧=满额（剩余制）
- [ ] GLM/Kimi 圆控件下第一行是倒计时行（●2h28m · ●6d11h 式），颜色随所属环、告警加粗
- [ ] 右上角“演示数据”角标可见（release 构建不显示——用 `npm run tauri build` 产物复核一次）
- [ ] 单击圆控件 → 详情卡窗口内覆盖弹出（值/绝对数/重置时刻+倒计时/口径文案/最后更新），点空白处收起
- [ ] 悬停圆控件 → tooltip 出各环剩余与重置倒计时
- [ ] ⚙ → 设置浮层：切“横排”布局变化、关“显示重置倒计时行”倒计时行消失、图例帮助区完整
- [ ] 灰化态演示（可选）：用 Edge 直接打开 `widget/ui/index.html?dev=1&gray=1` → 整体灰化+“⚠ daemon 不可达”

## 2. 拖动

- [ ] 按住顶部 ⠿ 手柄拖动窗口到新位置，松手
- [ ] 重启应用 → 窗口回到上次位置（位置记忆）

## 3. 托盘

- [ ] 托盘右键 → “收起到托盘”：窗口隐藏
- [ ] 托盘右键 → “显示悬浮窗”：窗口恢复并聚焦
- [ ] 点窗口 ✕（无装饰框则跳过）→ 等价收起到托盘，进程不退出
- [ ] 托盘右键 → “退出”：进程结束

## 4. 倒计时走字

- [ ] 保持窗口开着等 1–2 分钟：倒计时行分钟位 −1（演示态以契约 generated_at 为锚随真实分钟推进；接真数据后为真实时钟）

## 5. 票 04 · 显示配置与设置窗

配置文件位置：`%APPDATA%\com.ferryman.widget\profile.json`（tauri app_data_dir，与 window-state.json 同目录）。

- [ ] 托盘右键 → 「设置…」：独立设置窗弹出（有装饰框、居中、约 560×520、标题「显示配置」）；再点一次菜单不重复开窗、仅聚焦
- [ ] 关闭设置窗（✕）→ 任务管理器里该窗的 WebView 进程（msedgewebview2 子树）随之消失；反复开关 5 次，进程树无残留增长
- [ ] 设置窗改动即时生效：改环色/阈值/显隐/顺序/布局/倒计时开关 → 悬浮窗立刻重渲染，无需重启
- [ ] 月预算环（GLM/Kimi 行）：填预算（如 4000000 tok）→ 该圆控件出现内圈紫环、下方「月 X tok」文字行保留；清空 → 紫环消失、回到文字计数（现状）
- [ ] DeepSeek 预算环：勾「开」并填金额（如 100）→ 绿环出现（剩余制：1−本月花费/预算）；取消勾选 → 绿环消失
- [ ] 告警联动随阈值：把某行黄阈改大（如 85）→ 该对象原本蓝色的环按新阈值变黄
- [ ] 顺序：↑↓ 调换后悬浮窗圆控件顺序随动；显隐：关掉某行勾选 → 对应圆控件消失
- [ ] 重启应用 → 全部配置保持（profile.json 持久化；主窗 ⚙ 浮层的布局/倒计时开关改动同样保持）
- [ ] 损坏回落：手工把 profile.json 改成非法 JSON → 托盘重开设置窗，顶部黄条提示「已回落默认」、界面不崩；此时任意保存 → 文件被合法配置覆盖
- [ ] 缺失回落：删掉 profile.json → 重开设置窗提示「尚无配置文件（首次运行）」、用默认值、不崩
- [ ] daemon 侧零改动：本票不触碰 Go 代码与 /widget/summary 契约（`git status` 无 daemon 路径文件）
