来源：cc-switch（farion1231/cc-switch）coding_plan.rs / balance.rs 源码逐行核对，2026-09-21。悬浮窗不直接调这些端点——主程序查询器解析后按下方契约归一，widget 只见契约。

智谱 GLM · GET /api/monitor/usage/quota/limit（鉴权=裸 key，无 Bearer 前缀）

{
  "success": true,
  "data": {
    "level": "Pro",
    "limits": [
      { "type": "TOKENS_LIMIT", "unit": 3, "number": 5,
        "percentage": 38.0,        /* 已用%，无绝对值 */
        "nextResetTime": 1760000000000 },
      { "type": "TOKENS_LIMIT", "unit": 6, "number": 7,
        "percentage": 55.0, "nextResetTime": 1760300000000 }
    ]
  }
}
data.limits[unit:3] → 外环(蓝) 5h 剩余 = 100−percentage；data.limits[unit:6] → 中环(橙) 周剩余 = 100−percentage
坑位注记：unit 是唯一可信窗口分类锚（周期末尾周窗 reset 更早，按时间排序必标反，cc-switch #3036）；type 兼容 TOKENS_LIMIT/CREDIT_LIMIT；端点不给绝对值；老套餐只回 1 条（单环降级）；团队版 ?type=2 要额外 org 头。

Kimi Coding · GET api.kimi.com/coding/v1/usages（Bearer）

{
  "usage":   { "limit": 5000.0, "remaining": 2750.0, "resetTime": "…" },   /* 顶层=周窗 */
  "limits":  [ { "detail": { "limit": 1500.0, "remaining": 1200.0, "resetTime": "…" } } ]  /* =5h 窗 */
}
limits[].detail → 外环(蓝) 5h 剩余 = remaining/limit；usage → 中环(橙) 周剩余 = remaining/limit
坑位注记：数值口径在百分比/绝对数间漂移（limit≈100 时是百分比口径）→ 归一化永远对，绝对数展示防误读。

DeepSeek · GET api.deepseek.com/user/balance（Bearer）

{
  "is_available": true,
  "balance_infos": [ { "currency": "CNY", "total_balance": "110.00",      /* 字符串字面量 */
                      "granted_balance": "10.00", "topped_up_balance": "100.00" } ]
}
total_balance → 圆心 ¥余额；granted + topped_up → 详情卡拆两行；今/周花费 = 台账估算（官方无 usage API）

契约 v0：GET /widget/summary（widget 唯一数据源，30s 轮询）


    
每条 metric 自带 source（fetched/estimated）与 as_of/resets_at；顶层 version 字段，widget 对未知字段向前兼容；daemon 不可达=整体灰化，不假造数据。

    
resets_at 为 ISO 时刻（GLM=nextResetTime 毫秒时间戳在查询器内转换，Kimi=resetTime）；倒计时由 widget 本地计算并逐分钟刷新，不新增远端查询。
