# 用量悬浮窗 · 实施规格（2026-09-21）

> 来源：本 worktree grill 会话三轮（选型→ADR-0012；UI/契约 Round 3；开发计划 Round 4）。决策快照：评估报告决策记录 10/11、笔记 Round 3 与发现六。
> 架构（ADR-0012 钦定，不重开）：独立 Tauri 2 子项目 `widget/`（monorepo 三条件：自带构建面 / 永不 import Go 只认 HTTP 契约 / subtree 拆分出口）；余量查询与聚合统一在 Ferryman 本体；悬浮窗纯读；独立升级线。
> 节奏：壳（票 01–05）零冲突即动；数据面（票 06–08）阻塞于**渡口多上游 worktree 合并 + observe 周满（2026-09-27）**；联调（票 09–10）。

## Problem Statement

用户需要常驻可见的各家余量：GLM/Kimi 的 5h 窗与周窗剩余、距重置倒计时、月度用量（台账估算）、DeepSeek 余额与今/周花费（估算）、摆渡行花费。token 级用量只有 Ferryman 台账能出（五家服务商无此 API），显示端与数据面天然分工：主程序查与算，悬浮窗只读显示。显示端要独立演进、独立升级，不被主程序发布节奏绑死。

## Solution

Windows 置顶小窗（Tauri 2，vanilla JS（ES 模块）+JSDoc+SVG 前端）：每个受监控对象一个圆控件（环=剩余制多环 + 圆心标识 + 倒计时行 + 文字计数行），默认竖排贴右缘可切横排；单击展开详情卡；显示配置（显隐/环色/阈值/月预算/顺序/倒计时开关）全在 widget 本地。数据来自 daemon 只读聚合端点 `GET /widget/summary`（契约 v0，30s 轮询，倒计时本地推算逐分钟刷新）。

## User Stories

1. 作为用户，我想常驻置顶小窗一眼看到每个上游的 5h/周剩余环与重置倒计时（告警时变色），以便额度将尽时早做换上游/等待的决策。
2. 作为用户，我想看到 DeepSeek 的余额与今/周花费、各家月度用量，且估算值与查询值明确分标，以便不信错数字。
3. 作为用户，我想点圆控件看详情（值/上限/重置时刻/最后更新），以便核对口径。
4. 作为用户，我想自选显示哪些对象、每家单独一套显示配置，以便按需裁剪。
5. 作为用户，我想拖动悬浮窗并记忆位置、托盘收起、开机自启，以便它安静常驻。
6. 作为用户，我想 widget 独立检查与完成自升级，以便不装主程序新版本也能拿到 UI 改进。
7. 作为维护者，我想 widget 永不 import Go 代码、永不自持服务商凭据，以便安全边界清晰。
8. 作为维护者，我想 Rust/pnpm 工具链与 CI 路径过滤永不进主构建，以便主仓构建零感知。

## Implementation Decisions

- **前端栈**：vanilla JS（ES 模块）+JSDoc 类型注释+SVG，零构建链（仅 `@tauri-apps/cli` devDependency 驱动，不引入 TypeScript 编译或类型依赖——浏览器直接执行 JS，类型安全由 JSDoc 与编辑器检查承载；rev1 按 F1 澄清：D5 实质=零构建链 vanilla，原「TS」字样系措辞缺陷）；设置面将来若膨胀可迁 Vue，属纯前端内部事，契约不动（Round 4 Q1）。
- **窗口**：`visible:false` 先载后显（零闪窗铁律）；置顶/无边框/不出任务栏/不可缩放。窗体底色 v1 用不透明深色；真透明（亚克力/半透明）在票 02 实测后定（已知 Windows 透明窗鬼影风险，Tauri #14764）。
- **UI 语义**（Round 3 全裁）：环=剩余制，基色 蓝5h/橙周/紫月预算/绿DS预算，<20% 黄 <10% 红；倒计时行颜色随环、告警同步加粗；圆心=标识（DS 格放 ¥余额）；估算角标紫色虚线、查询角标绿色实线。
- **契约 v0**：`{version, generated_at, upstreams[], handoff{}}`；**upstreams 元素** = `{id, kind, label, plan?, metrics[], error?}`（id 稳定=渡口上游表条目名，渡口合并前后条目名若变、widget 显示配置按 id 建档会失配——票06/08 实施期核对，F6）；kind ∈ coding_plan|paygo；label=展示名；error=该上游整体查询失败时的 `{category, message?}`，category 为错误类别、永不带钥/URL）；**handoff** = `{id:"handoff", kind:"handoff", label, metrics[]}`（与 upstream 元素同形状，单对象非数组）；**metric** = `{key, remaining_pct|text, abs?, breakdown?, source: fetched|estimated, as_of, resets_at?}`（ISO）；**metric key 枚举** = window_5h / week / month_tokens / balance_cny / spend_today_cny / spend_week_cny / spend_month_cny（只增不改义；rev1 按 F2 补齐，取材自已验收 mock 内嵌 JSON）；**provenance 不进契约**——字段出处文案由 widget 按 kind+key 内置映射（传输瘦身）；顶层 version + widget 对未知字段向前兼容。
- **错误语义**：daemon 不可达=整体灰化+⚠（不假造数据）；上游单条失败=该 metric 缺席或 error 类别；主程序侧错误类别永不带钥/URL（照 balance.go 纪律）。
- **刷新与缓存**：widget 30s 轮询 + 从收起恢复即拉；倒计时由 resets_at 本地推算逐分钟刷新，零新增查询；主程序侧缓存：远端余量 5–15 分钟（各家限流）、台账聚合秒级。
- **显示配置**：widget 本地 JSON 持久化（tauri path API），daemon 零感知。
- **升级线**：tauri-plugin-updater + 签名 latest.json，endpoints 指向本仓 widget Release；tag 规范 `widget-v*`；检查更新只由托盘菜单手动触发。

## Testing Decisions

- 壳（03）：以 mock 的 Playwright 断言集为基线移植——圆心坐标、dasharray 数值、环色（含告警联动）、倒计时格式、tooltip/详情卡/横竖切换/收起/拖动、控制台零报错。
- 查询器（06）：table-driven 单测 + httptest 假端点（不真实外呼）；夹具=发现六全部形状分支：智谱 unit 双窗/老套餐单条/CREDIT 大小写两态/毫秒时间戳/信封有无 data；Kimi usage+limits[].detail、limit≈100 百分比口径；DS 字符串金额、granted/topped_up 拆分。
- 聚合（07）：与 /report 月口径交叉对账；5h 滚动窗边界单测。
- 端点（08）：golden JSON（version/source 枚举/resets_at ISO）；错误串断言不含 api_key 与 URL 原文。
- 契约变更纪律：改契约必须同 commit 改两侧（widget 与 daemon）——monorepo 的初衷。
