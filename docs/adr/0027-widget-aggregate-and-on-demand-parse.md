# 统计读路径：悬浮窗聚合索引＋人工面按需解析（常驻明细缓存改判撤销）

统计界面翻页 ~4 秒的病根是 daemon 每次查询都从头解析全量账本（2026-10-09 实测 91MB、19.5 万行）。战役首版解法是**常驻解析缓存**（全量明细驻留内存、增量追加、三重换文件侦测），实测暖后全量读 24ms——但常驻堆 **287MB**（19.5 万行 × 平均 16 键的 `map[string]any`，桶结构＋装箱头约占七成），远超立项估的 50~100MB。用户验收裁定：**省内存是开发纪律，不看机器余量（32GB 机器上 1% 也不驻留）；机器节奏的读者只需合计数，为其驻留明细不值；人工面是低频复盘，按需解析＋进度交互即可。**该缓存未上生产（PR 开着即改判），故本 ADR 在分支内改写而非另立新篇。

## Considered Options

- **A 悬浮窗聚合索引＋人工面按需解析（已选）**：常驻只留「模型×本地日」的 usage 四列＋handoff 计数（30 模型 × 31 日 ≈ 每月 40KB，滚动两月）；统计页/report/beats/回种等一律现解析，UI 带查询中交互。
- B 常驻明细缓存（首版已建）：287MB 常驻堆＋GC 余量翻倍（RSS ~500MB）；性能最好（24ms），但为低频人工面付常驻内存，违反上述裁定，撤销。
- C 热月降级（首版预留路径）：留当月 ≈70MB，但月初 7 天周窗跨月跳回 ~210MB，省得不干净；且仍是「为查询驻明细」思路，否决。
- D 全撤零常驻：悬浮窗 30s 轮询＝每 30s 全量解析 91MB（~4s CPU＋每轮 ~300MB 分配 churn），永续；轮询没有挂转圈的地方，否决。

## Decision

- **聚合索引**（`internal/accounts/accounts_aggregate.go`）：usage 四列按 lower(model)×本地自然日累计、handoff 按日计数；归属（model→上游）在查询时套 model_map——改上游配置不用重建，公式仍单源。滚动留最新两个月（悬浮窗月/周窗最大跨度）。
- **随写折叠**：Record 落盘成功即折叠，且**重新解析刚落盘的行**而非复用内存 entry——折叠与整建共用同一解析形状（JSON 数值一律 float64），杜绝两条取数路径分叉。
- **流式整建**：启动期后台一次（serve 同位替换旧 Prewarm），逐行解析→折叠→丢弃，峰值内存只多一行。**盘面戳核对**：折叠随写推进 (size, mtime) 戳，生产稳态零重建；测试直写/T39 式重写/文件增删由快照前核对侦测并整建——正确性永远以盘上字节为准。
- **锁序**：mu（Record 写盘）→ aggmu（折叠/换入），整建持 mu 读文件挡住并发记账，无反向嵌套。
- **按需解析读口**：Read/ReadMonths 恢复战役前语义（每次现读现解析；坏行每次读每报、撕裂半行按坏行丢——如实回退，非静默）；新增 **ReadWindow**＝Since 给定时按窗点名月文件（`MonthsBetween`），统计摘要/明细/qwatch 24h 扫描/report 全部改走——常规当月查询 ~1.2s 而非全量 4s。
- **统计窗撤自动轮询**（`widget/ui/stats.html`）：统计是复盘不是监控。查询时机＝开窗/切回（visibilitychange＋壳层 stats-restored 双保险）、翻页、改筛选（防抖）、手动刷新；隐藏启动零查询；查询中刷新按钮翻转态＋超时放宽到 20s。悬浮窗轮询改由聚合索引供给（`widgetLedgerAggregate` 消费快照，归属/月周桶边界与逐行版逐条等价）。

## Consequences

- 实测（真账本 91MB/19.5 万行，2026-10-09）：流式整建 2.3s（启动一次性）；**聚合常驻堆 0.3MB**（原常驻明细缓存 287MB，三个数量级）；快照 <1ms（98 usage 格＋22 handoff 格）；当月窗按需查询 0.53s、当月+上月 1.56s、全史按需 2.3s。全史查询期间进程 RSS 短暂冲高 ~500MB（按需解析的瞬态分配，GC 后回落）——常驻面为零，瞬态面以低频人工查询承接。
- 人工面查询回到秒级（窗内月文件 0.5~2.3s）——以进度交互承接，验收线从「翻页 ≤300ms、首开 ≤1s」改判为「带查询中交互的按需查询」。
- 悬浮窗数字在极端外部改写后可能短暂滞后一个轮询周期（盘面戳核对在下次快照时整建）；daemon 自身记账路径不受影响。
- 独立随行票保留：`[ferry] econ_provider` 计量键、价格表 stat 缓存（KB 级）、usage kind 下推/归日 memo（按需解析同样受益）。
- 明细不驻留后，`/beats`、dsh 回种、windows 富化等低频路径回到现解析成本（boot 一次性/闲置路径，可收）。
