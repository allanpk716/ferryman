# 账本只记事实，节省在 report 层重算

账本（accounts/*.jsonl）的六类流水（handoff/beat/block/inject/bypass/window）只记元数据与实收 token 数，**永不落节省金额**；成效账由 report 命令按版本化成效公式（v1：`S×(P_in−P_cache) − 注入×P_in − handoff成本`）+ 该流水钉死的价格表版本现算。理由：节省是反事实量，依赖"相对哪个平行世界"，公式必然演进——写入即陈旧；事实不变、随时可重算，且改价不重算旧账（每条流水钉死记账时版本）。与隐私不变量同源：账本是唯一事实源，report 只读。

## Considered Options

- **记账时顺带写入节省额**：公式升级后全账作废，两处真源漂移，审计时无法复算，否决。
- **只记事实、不算节省**：就是用户原话里"不可统计的玄学"，费用模块失去存在意义，否决。
- **节省额存缓存定期刷新**：缓存失效口径无版本语义，对账时新旧混存，否决。
