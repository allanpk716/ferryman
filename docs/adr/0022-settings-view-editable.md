# 设置视图可编辑：写经 daemon 写入器，密钥能存不能看，配置快照与还原

状态：已接受（2026-10-05 grill 两轮定案）。修订 ADR-0016-ferry 决定五「写只在 CLI」、ADR-0012「WebUI 换上游控件后置」、ADR-0014 widget「纯读消费者」措辞。

## 背景

改配置的唯一路径＝手编 config.toml＋重启守护；15900 面板只读被三处钉死（ADR-0016-ferry 决定五、ADR-0012 后置决定、CONTEXT.md 配置与调参页词条）。2026-10-05 用户要求：完整设置操作界面（日常修改/新增，风险操作除外）＋备份还原。探底事实（2026-10-05 调查）：配置**无热加载**（启动读一次，指针贯穿全程；现成热缝仅两处——`POST /provider_switch` 的 COW 换绑与 tuning 校准流水）；写原语已单源存在（config 包文本手术＋前置校验＋原子写，`provider add/remove` 即用）；daemon API 本带 Bearer token＋只绑回环；仓库四套备份（cutover 全量、接管同戳、安装、换装 exe）互不相干，config.toml 自身无自动快照、无还原入口。

## 决策

1. **编辑面＝工作台设置视图（ADR-0021）**，15900 面板维持只读至退役——不为将死的壳开写路径。除密钥显示外，全部配置条目可改、可增、可删。
2. **密钥能存不能看（write-only key）**：输入框可填可覆盖，任何展示面永不回显明文、只显尾四位；明文只存在于 config.toml 与配置快照，不入任何日志与响应。为何：加供应商手编 TOML 是日常最大痛点，但「界面里躺着全部明文密钥」不可接受——能存不能看两头都占。
3. **写路径＝daemon 写入器**：新增写端点挂 15700（继承 Bearer＋回环），复用 config 包既有写原语单源（文本手术＋校验＋原子写）；MCP/agent 面只读红线与降闸禁手不动。
4. **风险分层**：高风险二次确认并明示后果——删供应商、还原快照、闸门降级（enforce→off 加重确认）、换活跃供应商、改端口；中风险保存前预览改动——阈值、价格表、心跳参数；常规直接保存。闸门降级对设置视图放行（降闸禁手只限 agent 面——人的手不是 agent 的手）。
5. **生效语义 v1＝写盘＋安全重启**：保存时按字段标注「已生效/需重启」；界面内嵌「安全重启」按钮（静默门/排水路径，不裸杀）。热缝仅既有两处（provider_switch、tuning），不为其他字段新开热缝。为何：改动最频繁的「换活跃供应商」已是热切换；其余字段改动频率低，每开一条热缝是一张长期测试票。
6. **配置快照（config snapshot）**：每次保存前自动快照 config.toml（手动「立即备份」并存），含密钥（文件权限收紧），滚动保留 20 份于数据目录 `backups/config/`；还原前强制先快照当前态（还原本身可撤销），还原属高风险操作并随后安全重启；与接管备份/安装备份/换装备份/cutover 全量备份四套体系互不混用。

## 备选

- **15900 面板做过渡编辑页**：否决——15900 退役在即（ADR-0021），双壳双写路径徒增退役负担。
- **逐字段热应用**：否决（v1）——见决策 5；未来按字段逐个立票开缝，不改默认语义。
- **密钥完全留 CLI**（9-30 原豁免）：否决——痛点最大，且「能存不能看」已闭合泄露面。

## Consequences

- ADR-0016-ferry 决定五「写只在 CLI」修订为「写只在 daemon 写入器——CLI 与设置视图同为门面」；ADR-0012 的 WebUI 控件后置决定作废（换活跃供应商＝`provider switch` 热切换，进设置视图高风险层）；ADR-0014 widget 词条措辞修订：写一律经 daemon、自身仍永不自持凭据、永不 import Go 代码。
- CONTEXT.md 新词：工作台/设置视图/密钥能存不能看/风险分层/配置快照；「配置与调参页」词条改为随面板退役的历史页。
- 旧 `upstream use`（写＋重启）已弃用，不进任何界面。
- 界面实现流程沿用 ADR-0021：Kimi 出 mock → 用户过目 → 定稿实现 → 三道验收。

## 重开条件

无。若 v1 证明「写盘＋重启」卡日常，按字段立票开热缝——那是对本决策第 5 条的局部增量，不是翻案。
