# 同模型摆渡:捕获前缀追加重放复用渡口通道,参数走调参三态

2026-09-22 定案。背景:摆渡的模型叙事一直由第三方模型(本地/云端 Flash 档,OpenAI 协议摆渡供应商)另起炉灶撰写,整个转录按该供应商输入全价计费。新想法:会话上下文在自家渡口上游已有缓存,CC 之外用同钥匙+同模型+逐字节相同前缀发起请求同样命中。原前缀重放的机制有直接实验证据(Q14 段三实跳 3/3 臂首跳 ratio=0.998);**追加重放(前缀原样+末尾追加指令)的命中前提尚无实验覆盖,属待验证假设,已列为各上游启用的硬门槛(见决定一)**。

> 补记(2026-09-22 晚):本 ADR 经异构盲评两轮复审收敛,据此钉死四处口径——冷分支静默交还 25 分钟档、追加重放实跳臂为各上游启用硬门槛、判热时钟=距最后一次上游请求(含心跳重放)、调参生效值/建议值按上游分列;另留两条实施参考:新放行上游冷启动默认判冷、跳过遥测事件拆分原因。

**决定一(执行档)**:新增**同模型摆渡**档——对捕获的请求体做**追加重放**:前缀原样、末尾追加一条摆渡指令、放开 max_tokens,经渡口入站口走与真实流量相同的改写路径;命中则前缀按缓存读计价(GLM 1.7 vs 6.9 积分/万,DS flash $0.006 vs $0.30/M)。仅 CC 轨;上游白名单首发只放智谱(预置),DeepSeek 待补实跳臂后预置,Kimi(缓存按内容前缀哈希、忽略 cache_control、TTL 分钟级)与本地中转回退通道不放。**温度判据=距该会话最后一次上游请求(含体外心跳重放)的时长,加该上游 TTL 观测的闭式预判**——台账闲置不含心跳,不能用作判热时钟;闸门语义继续使用台账闲置,两个时钟各司其职;由此心跳保温中的会话在窗口收尾时判热成立。判冷或白名单未中则该次触发不执行同模型(见决定二冷分支口径)。隐私上同模型不引入新的一方(发给的仍是本来就有完整上下文的那家上游),比第三方更干净;L0/三层漏斗对其天然不需要(前缀必在自家窗口内)。

**【启用硬门槛】** 白名单预置不等于启用:任一上游(含首发智谱)的 same_model 实际启用,以"追加重放实跳臂"通过为准。成功标准四条:①追加消息后前缀仍命中(该跳缓存读占比不低于同前缀心跳基线);②与捕获快照的字节差异仅出现在末尾追加段;③stop_reason 非 tool_use;④输出可解析为交接 MD 结构。任一不满足则该上游保持未启用,实验结论回写白名单状态;同模型档默认 off,不与任何已确认决策冲突。

**决定二(时机)**:同模型档先于总结阈值触发。冷启动种子 20 分钟(E0a:15–25 分钟桶命中率中位 0.98,闲置 15 分钟后历史回归率约 0.4%),后续由策略计算器按遥测 TTL 分布+间隔分布+价格表现算并钳位于 [10min, 总结阈值];不变量链扩为:**同模型阈值 ≤ 总结阈值 ≤ 拦截阈值**。E0a 死亡带恰在原 25 分钟触发点(25–30 分钟桶中位 0.627、30–35 分钟 0.31),不提前就是跟尸体赛跑。

**【冷分支口径】** 判冷或当前上游不在白名单的会话,该次 20 分钟触发**不产生任何模型调用,静默交还既有调度**;第三方摆渡与骨架降级的触发时机**维持总结阈值 25 分钟不变**(已确认选项原文"外聘/骨架档维持 25 分钟不动"——"外聘"即今"第三方",同一次决策确认)。同模型档的提前只服务于判热会话吃缓存价差,不为任何会话提前第三方时机;判冷分支在遥测中记"同模型跳过"事件(跳过原因独立编码),不与 handoff 科目混淆。

**决定三(失败链)**:追加指令明令"只输出交接 MD 结构、禁止调用工具";max_tokens 封顶;stop_reason=tool_use 或输出不合交接格式即判该档失败 → 第三方摆渡 → 骨架(现链不动);同模型档不重试(防工具调用循环烧输出价,GLM 输出 24 积分/万是单价大头)。

**决定四(参数供给与调参三态)**:同模型阈值三层供给——冷启动种子 → 计算器闭式现算 → 扫参校准公式输入(只改输入、不旁路公式,红线不动);反跑评分总体从等待窗口扩到闲置/摆渡事件(数据源:E0a 型间隔分布+账本 usage/handoff 流水)。扫参建议的应用档位定为**调参三态**:manual 只出报告人手改 / recommend 默认(自动扫参+托盘提醒,人工应用)/ auto(护栏内自动应用+事后通报+一键回滚),永不自动升档;auto 五护栏:只改公式输入、建议值钳 [10, 总结阈值]、每上游每周至多一次生效、样本不足(滚动 30 天 <30 个摆渡事件)收敛为只提醒、生效后必须通报。据此 CONTEXT.md"扫参"词条的 Avoid 从"自动调参"收窄为"未经档位授权的自动应用"。

**【作用域】** 生效值与建议值**按上游分列**;总结阈值为全局不变量上限;手编配置上限默认全局单值、允许按上游覆盖;面板三列按上游分行,无 TTL 观测的上游显示"无建议"。

**决定五(交互与面板)**:通知=托盘气泡;看证据=报告 md + `ferryman tuning status` + 面板新增**配置与调参页**(只读:全配置总览、密钥一律打码、配置值/生效值/建议值三列对比、禁止混排——照抄 widget 查询值/估算值的分列规矩);写操作唯一路径是 CLI(`ferryman tuning apply/reject <id>`,与 `upstream use` 同款"配置变更是人手动作"文化),托盘与面板永不承担按钮。配置值语义:manual 档下即生效值,recommend/auto 档下是生效值上限(对齐等待上限"手动只能调低")。GUI 配置编辑缓议——为单一特性开写通道不值,留作全项目级决策。

**决定六(记账)**:同模型流水沿用 handoff 科目、结果码带 lane 标注;调参的接受/拒绝/自动应用落状态目录的 append-only 调参流水,不进账本(账本只记费用事件)。

## Considered Options

- **维持 25 分钟原阈值赌部分命中**:E0a 死亡带中位 0.627,四倍价差吃不到一半——否决。
- **先发探针(max_tokens=1 重放)验热再决定**:探针 miss 本身付全价前缀,防呆成本等于事故成本——否决。
- **Kimi 上游一并首发**:TTL 分钟级且未经 coding 端点实测,20 分钟触发大概率全灭——缓行,待实测 TTL 后重议。
- **扫参直接改运行参数 / 无条件自动应用**:旁路策略计算器唯一供给源红线;改为三态授权后 auto 档才是唯一合法出口。
- **面板加接受/拒绝按钮**:面板从只读变带写,写路径分散——否决,写只在 CLI。
- **widget 做 GUI 配置**:破 ADR-0014 纯读铁律——否决。

## Consequences

- doctor 新增检查:same_model 开而白名单空或全未启用;白名单条目启用于实跳臂结论未回写;tuning=auto 而价格表缺 p_cache(计算器拒算);同模型阈值与总结阈值钳位冲突。
- 默认 off,进 E1 评测候选集(与本地模型、DS Flash 同评质量+成本),E1 出结果前不当默认。
- 实施前置实验:智谱与 DeepSeek 各一发追加重放实跳臂(成功标准见决定一);追加 user 消息在 Anthropic 兼容端点的合并/断链行为属供应商端点怪癖,先查 cc-switch 参考实现再实跳验证,不猜。
- 交接产物不变:确定性骨架仍程序抽取,同模型只写模型叙事部分,两档产物同构;心跳保温的会话在窗口收尾时按判热口径天然判热,两机制咬合。
- 实施参考(非阻断):新放行上游在积累 TTL 观测前默认判冷落第三方(保守 bootstrap);"同模型跳过"遥测事件的跳过原因拆分独立编码(冷缓存/白名单未中/未启用),防误统计。
