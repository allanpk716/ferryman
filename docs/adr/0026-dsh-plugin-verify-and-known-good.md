# ADR-0026: DSH 插件验证与已知良好档案

DSH 宿主高频发版，ferryman-dsh 插件的失效多数无声（四形态：不加载／接口变／配置坏致流量绕渡口／会话键变，其中绕渡口无感漏钱最阴险），且 doctor 28 项零 dsh 检查（`.scratch/dsh-phase2/checklist.md` 已挂账未实施）。决定做一次性手动验证工具 `ferryman verify-dsh`（daemon 内单源实现、CLI 触发，MCP 面不进——ADR-0009 只读起步而探针有副作用），三层检测：L0 静态（三 profile 的 junction／insert 行／manifest 形状＋生产 cordis.patch.yml 三件）、L1 挂载（daemon 侧各宿主 `/dsh/poll` 报到年龄，超龄即挂——注册表在插件进程内存、外部不可读，poll 是唯一外部活信号）、L2 插件探针（复用 e2e 沙箱起栈：隔离 DSH_HOME＋四口 25xxx 铁闸，web 宿主单会话单消息走真模型，断言闸门到达／事件上报／会话键格式／注入路径四痕＋压缩链双道）。全绿落契约锚与已知良好档案，红灯复用 Pushover/Toast 降级告警通道并给出降级目标。

## Considered Options

- **常驻哨兵**（daemon 持续盯"宿主活而账本无痕"）：不做（v1）。判"宿主活着"得绕开插件本身（它死了不会报丧），只能拿会话文件 mtime 对渡口流量，有独立误报面；单独立项再议。代价＝DSH 更新到下次手动验证之间插件死了不知道，接受。
- **生产侧探针**（`--production` 往生产 web 宿主发真消息、验渡口改写运行时生效）：后置为可选模式。沙箱模型流量直连 z.ai 不经渡口，"配置坏绕渡口"形态的运行时证据有缺口，由 L0 静态三件（insert 行在、junction 完整、provider 指向渡口）兜底；真出现"静态全绿但运行时绕渡口"再启用。
- **探针走 mock 供应商省成本**：否。沙箱已兼得隔离与真实；mock 的假用量会让账本断言自说自话，而单条真消息成本仅几厘、频率仅每 DSH 更新一次。
- **压缩链后置给 e2e 专相**：否（2026-10-08 用户拍板）。压缩链进首轮探针，宁花 10-15 分钟全验，不留"更新后没验到压缩链"的窗口。
- **已知良好记成"支持范围"**：否。只背书真跑过验证的版本（判定流水＋最近全绿指针），没实测的版本不背书。

## Consequences

- 探针一轮 10-15 分钟量级（含压缩链相）；每次跑花一条真消息的钱（几厘级）。
- **契约锚**绿灯自动滚动、保留历史；DSH 升级后 diff 锚只复验漂移了的契约面（发现面／事件面／鸭子面／浏览器半面四类，daemon 五端点是自家代码不锚、走版本对账）。
- **已知良好档案**＝判定流水（DSH／插件／daemon 三元组＋判定＋锚哈希＋日期）＋最近全绿指针＋可选 installer 路径字段；降级预案依赖安装包留档习惯（照签名密钥灾备惯例）。
- 灯色纪律：黄（当前 DSH 版本未验证）只挂 doctor 不推送；红（验证失败／挂载超龄）才告警。自动处置（重装插件／降 DSH／降档）明确不做——人拍板。
- doctor 吸收 L0/L1 为常驻检查项（补上已挂账的 dsh 探针缺口；`ferryman-gate-dsh.ps1` 顺手补进 doctorScriptNames 七脚本清单）。

## 已知盲区登记（rev1 随首轮评审补入）

- **零会话宿主**：某宿主在跑但 poll 载荷 `sessions:[]` 时不贡献 sid，其插件死亡无灯变色；缓解需为 poll 加宿主身份字段（改插件协议，另行立项）。
- **desktop 功能覆盖边界**：插件探针仅验 web 宿主形态（沙箱）；Electron 桌面端只有静态/挂载验证，功能层验证为后置项。绿灯语义＝"web 沙箱功能全验证＋生产三 profile 静态/挂载验证"，输出按 profile 分层。
- **沙箱与生产同构纪律**：沙箱 daemon 用已安装生产 exe 起第二实例（不现场编译）；沙箱插件落点复刻生产 junction 布局；契约锚 diff 仅用于红灯定位，探针每次全跑。
- **活树近似**：生产 junction 直指仓库活树，沙箱 junction 指向验证时刻的备料快照——快照后活树再被改动时两者短暂分叉，插件探针绿灯背书的是快照而非活树当前态（窗口小，L0 junction 检查仍在；复审登记）。
