## 0 结论（一段话）

一场战役打完全部迁移面，然后一次性替换。**迁**：守护核心（守望/闸门/台账/交接库/账本/问询守望）、摆渡执行器、report/doctor/install 三条 CLI，共 21 个 Python 模块 6631 行 + 约 330 个行为测试；**不迁**：实验子系统（e0/e0b/e0c/eval/eval_set，≈2700 行）随 Python 打 tag 冻结。目标形态是仓库根部单一 Go module、单一 `ferryman.exe`（守护 7311 口 + 内嵌面板 15900 口 + 托盘），viewer 现有代码收编进来、其手抄的 policy 公式副本就地销毁——公式从此全仓一份。切换＝重生成点火脚本指到 exe，即日 enforce，问题靠 serve 日志 + 账本流水 + /stats 定位热修；回退＝一行命令指回 Python tag。

## 4 移植规则（全局铁律，逐任务沿用）

1. **规格=测试**：先移植该模块全部 Python 测试为 Go 测试（红）→ 实现（绿）→ commit。冻结面测试不迁。
2. **舍入**：Python `round()` 是银行家舍入（half-even）。一律 `mathx.Round(x, n)` = `math.RoundToEven(x*10ⁿ)/10ⁿ`。禁止 strconv/printf 的 half-up。账本 ts=3 位、dur=1 位、心跳成本=6 位、报表净额=4 位。
3. **时间**：全系统 float64 epoch 秒（含 mtime：`ModTime().UnixNano()/1e9`）；测试用 clock 注入，不打真实时钟。
4. **字符串按码点**：Python `len(str)`/切片按码点计数——Go 必须用 `utf8.RuneCountInString` 与 rune 切片助手（token_estimate、截断处处是坑）。
5. **路径键**：`pathsx.NormPath` = 反斜杠→正斜杠 + ToLower（lineage 断链防线）。
6. **锁**：Go mutex 不可重入。daemon 包统一锁序 **windowsMu（外）→ ledgerMu（内）**；凡需双资源的开窗临界区两把全拿、同序；台账公共方法自带锁、临界区用无锁内方法。绝不反向嵌套。
7. **HTTP/落盘兼容**：5 端点路径、Bearer、JSON 字段名、账本字段白名单与必填、index.json 结构、交接 MD 文案——与 Python 逐字段一致；两版输出比对用语义 diff（解析后比 map，不比键序）。
8. **正则**：RE2 无前后看、`\Z`→`\z`；`(?i)`/`(?s)` 内联旗标；包级 `var` 预编译。qwatch 剥代码块正则、extract CJK 范围（`\x{3000}-\x{9FFF}\x{FF31}-\x{FFEF}`）按 Python 字面精确平移。
9. **中文文案逐字**：block reason、警告、告警、日志、CLI 提示全部原文平移（日志驱动修复依赖同一套面孔认日志）。
10. **Windows**：构建 `-ldflags "-H windowsgui"`；不加 CGO 依赖（sqlite 用 modernc.org/sqlite 纯 Go）；PS1 的 BOM/控制字符纪律不动。

## 5 风险清单

| # | 风险 | 后果 | 对策 | 兜底 |
|---|---|---|---|---|
| R1 | 并发翻译错（RLock 可重入→Go 不可重入；Python 靠 GIL 的无锁读在 Go 不成立） | 死锁或双窗并存 | 规则 6 的统一锁序 + 临界区模式在计划里给出范式代码；test_merge_t51_parking_mutex 专项防守 | 死锁会挂住 /stats——doctor 探针 2s 超时暴露；回退一行命令 |
| R2 | 舍入口径漂移（half-even vs half-up） | 账本/报表数字与 Python 版对不上、"逐字段一致"无从谈起 | mathx 单点实现 + 单元测试钉死边界（x.5 两侧） | 账本 append-only，坏行不改写旧账，发现后修 code 即止 |
| R3 | rune/字节混用 | token 估算、500/1500 字截断错位（中文场景必炸） | 规则 4 + rune 助手函数全仓复用 | test_extract 边界用例 |
| R4 | 正则语义差（RE2） | 提问潮误判 → 等答复窗错开/漏开 | 逐条正则平移清单 + test_qwatch 全量 1:1 | qwatch 默认 off，风险受配置闸门控制 |
| R5 | 切换即 enforce，未验回归直击日常路径 | 误拦/漏拦/坏交接 | 切换手册的 24h 观察清单 + serve 日志逐事件留痕 | fail-open 语义：守护挂=放行，最坏退化为"不拦"，回到 Python 前的状态 |
| R6 | `-race` 在 Windows 需 gcc 工具链，本机未必有 | 少一道并发保险 | 有 gcc 就跑 `go test -race`；没有则靠锁序评审 + T20/T21 的并发用例 | R1 兜底同款 |
| R7 | sqlite 依赖（modernc 纯 Go）体积/成熟度 | exe 变大（~10MB 级）、慢 | 只在 installer/doctor 用读写；主守护路径零 sqlite | CC Switch 不在则整块跳过（Python 版同语义） |
| R8 | GBK 控制台下 Go stdout 中文乱码 | CLI 输出难读（不影响功能） | report 输出已是 UTF-8 文件可读；控制台乱码时 `chcp 65001` | 面板是主查看面 |
| R9 | systray 与守护同进程生命周期 | 托盘退出误杀守护 / 反之 | 沿 viewer 已验证形态：`go daemon.Serve()` + `systray.Run` 主线程阻塞；退出菜单=全进程退出（就是停守护，可接受） | `--no-tray` 模式照旧可跑 |
| R10 | 摆渡 provider 网络超时挂 goroutine | 内存缓慢增长 | chat() 全链 http.NewRequestWithContext；墙钟 480s 由 context 兜 | Python 版同样弃线程，语义持平 |
| R11 | 战役期 Python 规格冻结被突破（新功能票） | 移植返工、规格漂移 | ADR-0005 已声明冻结；破例需用户显式决策并接受返工 | — |

## 6 切换手册（T27 的操作规程）

**前置**（全部满足才动手）：
- `go build ./...` + 全部 Go 测试绿（约 330 个移植测试 + viewer 既有测试）；
- `ferryman.exe doctor` 全绿（钩子/脚本/BOM/快照/provider/daemon 探活）；
- 手工冒烟：真实会话触发一次 observe 警告 + 一次摆渡（真 provider）+ 一次归还注入，账本三行落账字段与 Python 版语义一致。

**切换日步骤**（顺序执行，每步可验证）：
1. `git tag archive/python-final && git push --tags`；
2. 构建 `ferryman.exe`（-H windowsgui）放到仓库根固定路径；
3. 停 Python 守护（taskkill 或等钩子下次自举前自然死亡）；删 `daemon.pid`；
4. 跑 `ferryman.exe install-cc`（重生成 start-daemon.cmd 指向 exe + 快照注入）+ `install-codex` + `--install-shortcuts`（桌面快捷方式改指 ferryman.exe）；
5. `ferryman.exe serve` 前台首启一次，看横幅与轮询日志正常，然后退出，交由钩子自举接管；
6. `ferryman.exe doctor` 全绿收尾；
7. 从 main 删除 ferryman/、tests/、pyproject.toml、uv.lock（提交信息注明 tag）。

**24h 观察清单**（日志驱动修复的抓手）：
- serve.out/err.log 无异常堆栈、轮询心跳持续；
- /stats：gate_calls 增长、health_alert 恒 false、qwatch 计数（若开）合理；
- accounts jsonl：block/inject/window/usage/handoff 各科字段齐全，金额舍入与 Python 同口径；
- 至少一次真实 block→/clear→归还注入全链路人工过一遍；
- 面板 15900 可开、时序图有当日数据。

**回退**（任何一步翻车）：start-daemon.cmd 的启动行改回 `python -m ferryman serve`（tag 里原样在），重跑 install-cc，即回 Python——数据格式互换，无需迁移。
