## 0. 范围与授权边界

- **T41 实装**：费用账本（六科目）+ report CLI + 策略计算器（纯公式）+ SYSTEM_PROMPT 两招（经 E1 验证）。
- **设计定案但不实装**：心跳执行器（体外重放运行时）。其授权需先过 §5 两道门槛。
- **职责边界**：机器等机器（主会话等子代理）归心跳；人不在的闲置归摆渡/闸门。

## 1. 费用账本

### 1.1 价格表（Q1/Q16）

- 宿主：本机 `config.toml`（T39 血统：不进代码、不进 git），`config.example.toml` 给 GLM 示例。
- 每条目：provider+model → `P_in` / `P_cache` / `P_out` + 自述单位（如 GLM 积分系数 6.9/1.7/24 每万 token）+ 生效日期。
- 版本化：每条流水**钉死记账时依据的价格表版本**，改价不重算旧账。
- 缺省语义：`P_cache` 允许缺省——缺省即无缓存经济，策略计算器**拒绝**推导心跳参数，report 标注"该 provider 节省额不可算"。宁可少报，不造数。

### 1.2 科目（Q2/Q15）

| 科目 | 记什么 | 记账点 |
|---|---|---|
| `handoff` | 摆渡每次模型调用（含 L2 分块、重试、**失败**） | `ferry.py`（usage 已捕获，接持久化） |
| `beat` | 每次心跳（执行器未授权前仅占坑） | 执行器（未来） |
| `block` | 闸门每次拦截 + 当时前缀规模 S | `server.py` gate |
| `inject` | 归还注入的交接 token 数（成本侧） | restore |
| `bypass` | 逃生门绕过（不计节省，反事实对照组） | gate |
| `window` | 等待窗口起止 + 当时 S（executor 无关，Q13 先行） | 子代理事件 handler |

**隐私不变量**：只记元数据与金额——时间、会话/族系/项目/Agent、token 数、单价版本、结果码；**永不落消息内容**。心跳体外重放走会话本就在用的同一路由，无新增内容暴露面。

### 1.3 存储与查询（Q4/Q5/Q7）

- 存储：数据根下 `accounts/YYYYMM.jsonl`，append-only，按月滚动（本地时区），每行带 schema 版本字段；全项目一本（行内带 project/session/agent）；不自动清理；**无历史可回填，从零起**。
- 统计单位：每条流水带 `session_id`（明细）+ `lineage_id`（聚合键）；**报表主视图按族系**——"这段对话总共花/省多少"，下钻文件明细。理由：block→inject→净节省因果链天然跨 resume。
- 查询：`ferryman account report`——人读表格 + `--json`；过滤 `--since/--until/--project/--session/--kind`；报告尾部附**复算附录**（价格表版本、公式版本、一行复算命令）。

### 1.4 成效账：节省的反事实口径（Q3）

```
每次拦截节省 = S×(P_in − P_cache) − 交接注入tokens×P_in − handoff成本
```

- 毛值/净值都报。
- **只有真实兑现的避免才计节省**：bypass 绕过的拦截不计（照付全量，入对照组）；保温期内会话未回归 → **无效保温**，纯亏损单列。
- 节省额只在 report 层由**版本化成效公式**计算，原始流水永不改写；公式升级旧报告可重算。

## 2. 策略计算器（Q6）

纯公式模块，无副作用，输入价格表 + 实测 TTL，闭式输出：

- 心跳间隔 `τ = 0.8 × T`（GLM：T=10min → 8min）
- 单次心跳成本 `= S×P_cache + ~300×P_out`
- 放任过期代价 `= S×P_in`
- 心跳划算的等待上限 `≈ τ × S×(P_in−P_cache) / 单次成本`（GLM S=150k：~25–28min；S 越小上限越短，300×P_out 项占比变大——30k 下限即为此而设）
- 宽限期（默认 5min）与最小前缀阈值（默认 30k）的推导默认值，config 可覆盖
- 分档决策矩阵：≤8min 不作为 / 8–28min 心跳 / ≥28min 放任过期（大前缀先 compact）
- 无 `P_cache` 输入 → 拒绝输出心跳参数

## 3. 心跳（设计定案，未实施）

### 3.1 触发状态机（Q8）

- **开窗**：子代理派发事件（现有 `/subagent` 钩子）→ 主会话进入等待窗口；跟踪该会话**在飞子代理集合**（含嵌套）。
- **起跳**（全部满足）：主会话闲置超宽限期 + 台账前缀 ≥ 阈值 + opt-in。
- **节律**：每 τ 一跳，间隔自上一次成功 HIT 起算。
- **停跳**：**最后一个子代理完成**（agent loop 自动续跑，暖缓存即刻兑现）或主会话恢复写入或等待超划算上限（记"放任过期"事件）。
- 全程默认 off，config 显式开；状态与累计花费随时可查、一键停。

### 3.2 执行器载体（Q9）

体外重放：daemon 从会话文件读稳定前缀（复用摆渡稳定快照机制），按该 Agent 请求形状**逐 token 重构**（不一致即全 miss），直打 CC Switch 本地代理（与真实使用同计费同缓存路由），`max_tokens` 压最小，不写会话文件、聊天界面无感。前缀重构机器自 `experiments/cache-ttl/` pi 轨移植。**先只做 CC 轨**（Codex rollout→请求重构复杂度高，挂后续）。

### 3.3 自校验回路（Q10）

- 每跳：预期 cacheRead ≈ S，实收 ratio ≥0.85 判 HIT；记预测 vs 实收对账行。
- miss：记异常 + notify 告警 + **停跳**（连续 miss = 服务端策略漂移，继续跳纯烧钱）+ 建议重跑 `experiments/cache-ttl/`。
- TTL 宿主：config.toml（带 measured_at 与来源报告）；**自适应只告警建议、不自写 config**——改数必须人工审过留痕。
- **地面真值**：闭窗后主会话 jsonl 下一条 assistant 记录的实收 cacheRead（守望本来就在读文件，免费取得）。

### 3.4 "有意义节约"的证明（Q11/Q13）

- 事后策略对比：对每个已闭窗口（时长 d、前缀 S 已入账），并排算四策略成本——①不作为 ②心跳 ⌈d/τ⌉ 跳 ③放任+等待前 compact ④超时交接——实际策略标记；总体聚合"若全用最优可省 X"。
- 事前仿真（T41 即有）：report 基于 `window` 流水出"若心跳开启"仿真节——**证明先于实施**。
- 裁决门槛：≥30 个窗口或两周数据后再决定授权。

## 4. 交接质量顺手改进（Q12）

`ferry.py` SYSTEM_PROMPT 增两条（源自 Matt Pocock /handoff 技能的自省，经 E1 验证后合入）：

1. **断言降级**：模型叙事中未验证的断言（"X 已完成"）必须显式标注为推测——下一个代理把交接当合同，不复查。
2. **引用不复制**：已成文内容（spec/ADR/issue/diff）给路径不抄录——文件更小、不与真源漂移。骨架逐字文件清单保留（防幻觉锚）。

（评估结论：Matt 技能与本项目交接是两个生态位——他的要活会话+人工触发，我们的要冷 jsonl+无人值守；不换，偷两招。）

## 5. 验证链（顺序即信任顺序）

1. 单测：公式（计算器）/ 账本（append-only、钉版本、缺省语义）
2. E1：prompt 新旧对比（Q12 两招）
3. 窗口数据积累（`window` 科目，≥30 或两周）
4. 真实分布上的策略仿真（report 事前仿真节）
5. **CC 保真度实验（执行器硬门槛，Q14）**：真实 41k+ CC 前缀，daemon 式体外重构直打 CC Switch 代理 ×3，HIT ratio ≥0.85 才谈执行器
6. 执行器授权裁决（用户明确放行）
7. pilot 实测对账（预测 vs 实收 vs 地面真值）
