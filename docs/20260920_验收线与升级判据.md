# Ferryman 核心目标验收线与升级判据（2026-09-20 grill 定稿）

来源：2026-09-20 grill 会话两轮共 11 问，用户逐条确认（"都同意"×2）。本文是共识的书面形态，判据此後不再口头重议。

## 一、验收线（什么算"达成核心目标"）

三条全部可查，达成即算核心目标完成：

1. **闸门**：CC 轨 enforce 态运行，且一周误拦 ≤1 次（"误拦"＝不在任何合法拦截理由内的 block，豁免三判据漏判计入）。
2. **心跳**：等待窗泳道在真实等待窗中兑现 ≥1 次可记账的节省（beat 科目有正成效账：窗口收尾后主会话首发实收 cacheRead 为地面真值）。
3. **成效账**：月度 net > 0，且无效保温（wasted warming）占心跳总花费 < 10%。

## 二、闸门 observe→enforce 升级判据

- observe 满 **7 天**（自 2026-09-20 装回钩子起计）；
- 期间所有警告逐条归因，**"应豁免而未豁免"＝0**（三道判据：子代理计数>0 / 转录尾部有未等到结果的工具调用 / 停车窗未过期，任一成立即必须豁免）；
- 人工复核警告列表，无误拦（即所有警告的会话确实凉了且已有有效交接）；
- 出现任何一条豁免漏拦 → 修复后重新计时 7 天。
