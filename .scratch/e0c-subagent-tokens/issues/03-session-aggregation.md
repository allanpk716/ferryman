# 03 · 会话聚合器 + 族系 + 快照一致性

## What to build
把主转录 + 全部子代理装配成会话总账,并产出:
- 会话总账 = 主文件四列加总 + Σ 子代理 self;direct/total spawn count;subtree(按 toolUseId 父链);
- 交叉校验(direct 口径):主文件 Agent/Task tool_use 数 vs depth=1 meta 数 vs depth=1 转录数;(total 口径):各父转录直接子调用数合计 vs total spawn 事件数;差值进长尾;
- 快照一致性:每文件记(扫描时刻, 字节大小, sha256);会话记扫描窗口起止;**末尾重枚举一次**,新增文件标"扫描窗口外"进长尾;活跃会话(mtime<5min)整场标"在跑(非终值)"不进终值汇总;
- 族系合计行:复用台账既有 lineage 识别规则,输出链上会话 id 列表,整行标"识别未验证"。

## 验收标准
- [ ] 会话总账数字 = 主 + Σ 子(含嵌套),不双计
- [ ] 交叉校验两口径差值正确落入长尾
- [ ] 末尾新增文件被标"扫描窗口外"
- [ ] 在跑会话不进终值汇总、单独成节
- [ ] 族系合计行带会话 id 列表与"识别未验证"标注
- [ ] 合成会话树 fixture 单测全绿
