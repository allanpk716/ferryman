# 票 02 · 窗口与常驻形态

## What to build

悬浮窗常驻行为包：拖动移动 + **位置记忆**（退出前保存、启动恢复，多显示器坐标）；托盘（菜单：显示悬浮窗/收起到托盘/设置…/检查更新(占位)/退出，托盘图标常驻）；**单实例**（tauri-plugin-single-instance，注册在 Builder 最前——二次启动拉起既有窗口后退出）；**开机自启**（tauri-plugin-autostart，默认关，设置里可开）；图标集生成（`cargo tauri icon`，源图=圆控件风格 PNG）；窗体底色实测拍板：不透明深色 vs 真透明（Windows 透明窗鬼影风险 Tauri #14764，实测定夺并记录）。

## 验收标准

- [ ] 拖动后退出重启，位置复原（含负坐标/副屏）
- [ ] 托盘菜单四项全部可用；关窗=收起到托盘而非退出（退出只走托盘菜单）
- [ ] 二次启动不出现第二个窗口/进程，既有窗口被拉到前台
- [ ] 任务栏永不出现悬浮窗条目；启动零闪窗（visible:false 先载后显）
- [ ] 自启默认关闭；开启后注册表 Run 键写入正确（实测）
- [ ] 底色决策与理由记录进本票（或笔记）
